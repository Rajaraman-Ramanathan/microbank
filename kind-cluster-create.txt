*) creating clusters in different network (VPC) in kind simulating multi vpc cluster
   and vpc peering:
1. create two docker networks.
   docker network create argocd-net
   docker network create dev-net
2. kind create cluster --name argocd-hub
3. docker network connect argocd-net argocd-hub-control-plane
4. verify argocd in correct network
   i) docker inspect argocd-hub-control-plane
   ii) docker network inspect argocd-net - optionally from network perspective
5. create dev cluster
   kind create cluster --name microbank-dev --config=kind-cluster-config.yaml
6. docker network connect microbank-dev-net microbank-dev-control-plane
7. create peering network
   docker network create peering-net
8. connect controlplane of both cluster to peering network.
   docker network connect peering-net argocd-hub-control-plane
   docker network connect peering-net microbank-dev-control-plane

kubectl apply -f https://github.com/kubernetes-sigs/metrics-server/releases/latest/download/components.yaml

*) To overcome self signed TLS issue in microbank-dev cluster:
kubectl patch deployment metrics-server -n kube-system \
  --type='json' \
  -p='[
    {"op":"add","path":"/spec/template/spec/containers/0/args/-","value":"--kubelet-insecure-tls"},
    {"op":"add","path":"/spec/template/spec/containers/0/args/-","value":"--kubelet-preferred-address-types=InternalIP"}
  ]'
kubectl rollout restart deployment metrics-server -n kube-system

*) Create RBAC and secrets for argocd:
1. create service account, cluster role, cluster role binding and cluster secret for argocd
2. manually apply these resources in microbank-dev cluster for the first time.
   kubectl apply -k platform/bootstrap/rbac
3. Then create token for arocd-manager
   kubectl create token argocd-manager -n kube-system
4. Get CA certificate
   kubectl config view --raw -o jsonpath="{.clusters[?(@.name=='kind-microbank-dev')].cluster.certificate-authority-data}"
5. switch to argocd-hub cluster and create cluster secret for argocd
